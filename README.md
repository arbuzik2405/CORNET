# CORNET

Универсальная утилита для веб-мониторинга и анализа изменения платформ. (Universal web monitoring and change detection platform).

## Overview

CORNET monitors selected internet sources, detects changes,
stores snapshots and events, and sends notifications through Telegram.

## Initial scope

- Public HTML page monitoring
- Content normalization
- Change detection
- Snapshot history
- Telegram notifications

## Technology

- Python
- FastAPI
- aiogram
- PostgreSQL
- SQLAlchemy
- Docker Compose

## Project status

На этапе ранней разработки — MVP.

## Security

Never commit credentials, API tokens, private keys or `.env` files.
